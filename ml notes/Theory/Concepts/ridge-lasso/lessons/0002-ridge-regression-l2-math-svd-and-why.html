Lesson 02 of 05 · Ridge Regression (L₂)

Ridge Regression: Step-by-Step Derivation, Eigenvalues & SVD

Derive the closed-form Ridge estimator on a whiteboard without stumbling, then uncover its deeper linear-algebra superpower: surgical shrinkage along low-variance principal components.

~8 min read + interactive SVD lab Win: Derive β̂ridge & explain dⱼ²/(dⱼ²+λ) cold

1. Step-by-Step Derivation of the Ridge Closed Form

Assume predictors X (n × p) are standardized and target y is centered (so β̂₀ = ȳ drops out cleanly). We want to minimize the Ridge objective:

J(β) = (y − Xβ)ᵀ(y − Xβ) + λ βᵀβ   (λ > 0) Note: scikit-learn's Ridge uses the same formula (alpha = λ) without dividing by 2n.[sklearn §1.1.2]
  1. Expand the quadratic form:
    J(β) = yᵀy − 2βᵀXᵀy + βᵀXᵀXβ + λβᵀIβ Why: Since yᵀXβ is a scalar, it equals its transpose βᵀXᵀy, combining the two cross-terms cleanly. Writing λβᵀβ = βᵀ(λI)β prepares us to factor out β.
  2. Differentiate with respect to vector β and set to 0:
    ∇βJ(β) = −2Xᵀy + 2XᵀXβ + 2λIβ = 0 Why this works globally: Every term is smooth and quadratic. The Hessian is H = 2(XᵀX + λI), which is strictly positive definite for any λ > 0 — guaranteeing a single, unique global minimum.
  3. Factor and solve for β̂ridge:
    (XᵀX + λI) β̂ridge = Xᵀy  ⇒  β̂ridge = (XᵀX + λI)⁻¹ Xᵀy Why the inverse ALWAYS exists: Even if XᵀX is singular (p > n or duplicate columns) with zero eigenvalues, adding λI shifts every eigenvalue from dⱼ² ≥ 0 to dⱼ² + λ > 0. A matrix with all strictly positive eigenvalues is always invertible!
Interview Trap: Do NOT invert (XᵀX + λI) blindly if you kept the intercept column! If your design matrix includes a column of 1s for the intercept, replace I with I₀ = diag(0, 1, 1, …, 1) so the intercept receives 0 penalty. Catching this detail unprompted signals real practical experience.

2. The Deeper "Why": SVD & Effective Degrees of Freedom

Saying "Ridge adds λI to make the matrix invertible" is a good mid-level answer. A senior-level answer goes one layer deeper using the Singular Value Decomposition (SVD) of centered X = U D Vᵀ:[ESL §3.4.1]

Step-by-step SVD derivation of Ridge fitted values

Show how Xβ̂ridge simplifies to shrinking principal components

Substitute X = U D Vᵀ (where UᵀU = I and VᵀV = VVᵀ = I):

  1. XᵀX = V D² Vᵀ, so XᵀX + λI = V (D² + λI) Vᵀ.
  2. Invert it easily: (XᵀX + λI)⁻¹ = V (D² + λI)⁻¹ Vᵀ.
  3. Multiply by X on the left and Xᵀy on the right:
    ŷridge = Xβ̂ridge = U D (D² + λI)⁻¹ D Uᵀ y = Σj=1..p uⱼ · [ dⱼ² / (dⱼ² + λ) ] · (uⱼᵀ y) Compare with OLS (λ = 0): ŷOLS = Σ uⱼ (uⱼᵀ y). Ridge multiplies each PC coordinate by dⱼ² / (dⱼ² + λ).

What this proves: dⱼ² is the variance of the data along the j-th principal direction. When dⱼ² is tiny (collinear / noisy direction), dⱼ² / (dⱼ² + λ) ≈ 0 — Ridge crushes it! When dⱼ² is large (strong variance direction), dⱼ² / (dⱼ² + λ) ≈ 1 — Ridge barely touches it! Unlike Principal Components Regression (PCR) which hard-truncates PCs, Ridge smoothly shrinks them.

Effective Degrees of Freedom df(λ) & Why Ridge Splits Correlated Weights

Effective degrees of freedom: Taking the trace of the Ridge hat matrix Hλ = X(XᵀX + λI)⁻¹Xᵀ gives:

df(λ) = tr(Hλ) = Σj=1..p dⱼ² / (dⱼ² + λ) df(0) = p (full OLS complexity)  →  df(∞) = 0.

Why Ridge shares weight equally across identical features: Suppose x₁ = x₂ and their combined effect must sum to 2 (β₁ + β₂ = 2). Putting (2, 0) costs penalty 2² + 0² = 4, while splitting (1, 1) costs 1² + 1² = 2 — half the penalty for the exact same RSS! That is why Ridge shrinks correlated predictors together.

4. Why Ridge Never Produces Exact Zeros

Two complementary reasons — always give both in an interview:

  • Calculus / Gradient reason: The derivative of λβⱼ² is 2λβⱼ. As βⱼ → 0, the penalty pull itself shrinks toward 0! Once βⱼ is tiny (say 0.001), reducing it further saves almost zero squared penalty (0.001² = 10⁻⁶), so even a whisper of noise in y keeps βⱼ ≠ 0.
  • Geometric reason: Constraining Σβⱼ² ≤ t forms a smooth circle / hypersphere with no corners on the axes (you'll explore this interactively in Lesson 03).

Whiteboard Proof Drill · 90 seconds

Interviewer asks: "On the whiteboard, derive β̂ridge from the loss function, prove it is a global minimum, and explain what happens computationally when p = 50,000 and n = 200."

Write/speak your derivation first, then check the senior rubric
  • Derivation: Expand (y − Xβ)ᵀ(y − Xβ) + λβᵀβ, differentiate to −2Xᵀy + 2(XᵀX + λI)β = 0, solve β̂ = (XᵀX + λI)⁻¹Xᵀy.
  • Global minimum proof: Hessian 2(XᵀX + λI) is strictly positive definite (all eigenvalues dⱼ² + λ > 0).
  • Bonus Senior Trick (Woodbury / Dual Form when p ≫ n): Inverting a 50,000 × 50,000 matrix costs O(p³)! Use the push-through / Woodbury identity: (XᵀX + λIₚ)⁻¹ Xᵀy = Xᵀ (XXᵀ + λIₙ)⁻¹ y — inverting a tiny 200 × 200 matrix instead (O(n³))! This is also the exact bridge to Kernel Ridge Regression.
