Scenario 1 · Code Review Bug Hunt

Spot every bug in this candidate's scikit-learn script:

scaler = StandardScaler()
X_s = scaler.fit_transform(X)          # Bug 1?
model = Lasso(alpha=1.0)
scores = cross_val_score(model, X_s, y, cv=5)
# Compare directly with Ridge at "same" regularization:
ridge = Ridge(alpha=1.0)               # Bug 2?
# Feature importance from Lasso on correlated ad-spend channels:
selected = X.columns[model.fit(X_s, y).coef_ != 0]  # Bug 3?
Reveal all 3 bugs and the production fix
  1. Data leakage: StandardScaler().fit_transform(X) ran before CV. Fix: put StandardScaler() and the estimator inside a Pipeline.
  2. Apples-to-oranges alpha=1.0: Ridge and Lasso penalties have different norms AND scikit-learn scales Lasso's RSS by 1/(2n) while Ridge does not. Fix: tune each model's alpha independently via RidgeCV / LassoCV on a log grid.
  3. Fragile feature importance under correlation: Lasso picks arbitrarily among correlated ad-spend channels (e.g., Facebook vs. Instagram spend) and zeros the rest. Dropping a channel just because Lasso zeroed it can mislead business stakeholders! Fix: inspect correlation clusters, use Elastic Net, or check stability selection across bootstrap resamples.

Scenario 2 · System & Modeling Design

Interviewer asks: "We have 25,000 gene expression features and only 180 patient samples. Genes act in highly correlated biological pathways, and biologists need an interpretable list of active pathways. Would you use OLS, Ridge, Lasso, or Elastic Net — and why?"

Reveal senior rubric
  • Eliminate OLS: p = 25,000 ≫ n = 180 → XᵀX is massively rank-deficient; infinitely many 0-training-error solutions.
  • Eliminate pure Ridge: Solves p ≫ n cleanly (especially via the dual 180×180 Woodbury trick), but keeps all 25,000 genes non-zero — useless for biologist interpretability.
  • Eliminate pure Lasso: Two fatal flaws here: (1) capped at selecting at most n = 180 genes, and (2) within a correlated biological pathway, Lasso picks one gene arbitrarily and hides its pathway partners.
  • Pick Elastic Net: Preserves sparsity for interpretability, lifts the n-feature cap, and its L₂ component induces the grouping effect so correlated genes in a pathway enter together. Tune (α, l1_ratio) with nested CV + 1-SE rule inside a standardization Pipeline.

Scenario 3 · "Prove It Three Ways" Classic

Interviewer asks: "Give me THREE distinct explanations of why Lasso yields sparse weights while Ridge does not — one geometric, one calculus/optimization, and one Bayesian."

Reveal 3-angle rubric
  1. Geometric: The L₁ constraint region (diamond / cross-polytope) has sharp corners on the coordinate axes; expanding elliptical RSS contours hit a corner first (βⱼ = 0). The L₂ region (hypersphere) is smooth everywhere with no axis corners.
  2. Calculus / Optimization: L₂'s penalty gradient 2λβⱼ → 0 as βⱼ → 0 (diminishing pull near zero), whereas L₁'s subgradient keeps a constant pull of ±λ all the way to 0, yielding soft-thresholding with dead-zone [−λ/2, +λ/2].
  3. Bayesian MAP: Ridge is MAP under a zero-mean Gaussian prior (flat, smooth slope 0 at origin); Lasso is MAP under a zero-mean Laplace prior (sharp cusp / spike at 0 that pulls weak posteriors onto the mode at βⱼ = 0).

Scenario 4 · Subtle Math Pushback

Interviewer asks: "Wait — if I run Ridge with a huge λ, say λ = 10⁹, won't the coefficients be so close to 0 that it's basically zero anyway? Why do we care about exact zeros?"

Reveal senior rubric
  • Shrinking everything destroys signal: Pushing λ → 10⁹ crushes true strong signals along with noise (massive underfitting / high bias).
  • Selective zeroing vs. global shrinkage: Lasso lets you keep strong predictors large (only shifting them by constant λ/2) while setting weak noise predictors to exact zero — reducing serving latency, feature-pipeline maintenance cost, memory footprint, and improving interpretability.

Scenario 5 · Coding From Scratch

Interviewer asks: "Without scikit-learn, how would you write a 10-line NumPy Coordinate Descent loop for Lasso on standardized X and centered y?"

Sketch the algorithm first, then check the clean NumPy implementation 
import numpy as np

def soft_threshold(z, gamma):
    return np.sign(z) * np.maximum(np.abs(z) - gamma, 0.0)

def lasso_cd(X, y, lam, n_iter=200):
    n, p = X.shape
    beta = np.zeros(p)
    r = y.copy()                        # maintain residual r = y - X @ beta
    col_norms = np.sum(X ** 2, axis=0)  # ||x_j||_2^2
    for _ in range(n_iter):
        for j in range(p):
            old_b = beta[j]
            r += X[:, j] * old_b        # partial residual r^(-j)
            rho = X[:, j] @ r           # correlation with partial residual
            beta[j] = soft_threshold(rho, lam / 2.0) / col_norms[j]
            r -= X[:, j] * beta[j]      # O(n) incremental residual update!
    return beta

Why interviewers love the incremental r update: Updating r += xⱼβⱼ_old then r -= xⱼβⱼ_new makes each coordinate step O(n) instead of recomputing Xβ in O(np), reducing a full pass over all features from O(np²) to O(np)!
