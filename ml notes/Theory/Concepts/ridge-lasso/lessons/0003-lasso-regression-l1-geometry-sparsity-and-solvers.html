Lasso (L₁): Why It Produces Exact Zeros, How It Solves, and Where It Fails

Understand sparsity both geometrically (the diamond) and algebraically (subgradients & soft-thresholding), see how Coordinate Descent actually solves it, and learn the two failure modes interviewers probe.

~9 min read + 2 interactive labs Win: Prove L₁ sparsity two ways & explain Coordinate Descent

1. The Constrained View: Why L₁ Creates Exact Zeros

By Lagrange duality, minimizing the penalized Lasso objective RSS(β) + λ Σ|βⱼ| is equivalent to minimizing RSS(β) subject to a budget constraint Σ|βⱼ| ≤ t (smaller t ↔ larger λ).[Tibshirani 1996]

In 2D, constant-RSS curves are ellipses centered at β̂OLS. As you expand the ellipse outward from β̂OLS, the very first point where it touches the feasible constraint region is the regularized optimum β̂*:

  • L₂ Circle (Ridge): Smoothly curved everywhere with no corners on the axes → the ellipse touches a curved side where both β₁ ≠ 0 and β₂ ≠ 0.
  • L₁ Diamond (Lasso): Sharp corners stick out directly along the coordinate axes → the expanding ellipse is overwhelmingly likely to hit a corner first, setting β₁ = 0 (or β₂ = 0) exactly! In higher dimensions, the diamond is a cross-polytope with exponentially many edges and corners sitting on sparse subspaces.

2. The Algebraic Proof: Subgradients & Soft-Thresholding

A diamond drawing is great intuition, but interviewers often ask: "Prove it with calculus — wait, |β| isn't differentiable at 0, so how do you even differentiate it?"

Use the subdifferential! For a convex function with a kink at 0, the subdifferential of |β| is:

∂|β| = { +1 if β > 0,   −1 if β < 0,   [−1, +1] if β = 0 } A convex function attains its global minimum at β* if and only if 0 ∈ ∂J(β*).
  1. Take the orthonormal case (XᵀX = I) so every coordinate decouples:
    Minimizing ‖y − Xβ‖₂² + λ‖β‖₁ decouples into p independent 1D problems: minβⱼ (βⱼ − zⱼ)² + λ|βⱼ|, where zⱼ = xⱼᵀy = β̂OLS,j. Why this simplification matters: Every step of Coordinate Descent on general (correlated) X reduces to this exact 1D problem!
  2. Set 0 ∈ ∂[ (βⱼ − zⱼ)² + λ|βⱼ| ] = 2(βⱼ − zⱼ) + λ · ∂|βⱼ|:
    • If βⱼ > 0: 2(βⱼ − zⱼ) + λ = 0 ⇒ βⱼ = zⱼ − λ/2 (valid only when zⱼ > λ/2).
    • If βⱼ < 0: 2(βⱼ − zⱼ) − λ = 0 ⇒ βⱼ = zⱼ + λ/2 (valid only when zⱼ < −λ/2).
    • If βⱼ = 0: we need 0 ∈ −2zⱼ + [−λ, +λ], i.e. |zⱼ| ≤ λ/2!
    Why exact zero happens algebraically: Unlike Ridge's derivative 2λβⱼ (which fades to 0 near the origin), Lasso exerts a constant pull of ±λ right down to 0, creating a dead-zone [−λ/2, +λ/2] where weak signals snap flat to 0.
  3. Package into the Soft-Thresholding Operator:
    β̂lasso,j = S(zⱼ, λ/2) = sign(zⱼ) · max(|zⱼ| − λ/2, 0) Compare with orthonormal Ridge: β̂ridge,j = zⱼ / (1 + λ) (proportional scaling, never hits 0).

3. How Lasso Is Actually Solved (No General Closed Form!)

When predictors are correlated (XᵀX ≠ I), coordinates couple together and there is no closed-form formula because of the non-differentiable kinks at βⱼ = 0. How do modern libraries like glmnet and scikit-learn solve it so fast?[Friedman et al. 2010]

Compare the 3 Lasso optimization algorithms

1. Cyclical Coordinate Descent (Default in scikit-learn & glmnet)

How: Hold all weights except βⱼ fixed, compute the partial residual r(−j) = y − Σk≠j xₖβₖ, and update βⱼ ← S(xⱼᵀr(−j), λ/2) / ‖xⱼ‖₂². Cycle through j = 1…p until convergence.

Why it converges to the global minimum: Coordinate descent can fail on general non-smooth functions, but Tseng's theorem guarantees global convergence whenever the non-smooth part is separable across coordinates (Σ|βⱼ| splits cleanly by coordinate!). Warm-starting across a grid of λ values from large to small makes it blazingly fast.

2. Proximal Gradient Descent (ISTA / FISTA)

How: Take an ordinary gradient step on the smooth RSS part (β − η∇RSS(β)), then apply soft-thresholding S(·, ηλ) to every coordinate.

Why not vanilla Gradient Descent? Vanilla GD steps back and forth across the kink at 0 forever, producing 0.00013, −0.00009 — never exact zero. The proximal step snaps anything near zero cleanly to 0.

3. LARS (Least Angle Regression)

How: Starts with all β = 0, finds the predictor most correlated with residual y, moves along it until another predictor ties in correlation, then moves along their equiangular direction — computing the entire exact piecewise-linear path for all λ values in O(p³) (same order as one OLS fit).[ESL §3.4.4]

Trade-off: Great when p is moderate and you want the exact path, but Coordinate Descent beats it on huge sparse datasets.

4. Lasso's Three Famous Limitations (Bridge to Lesson 04)

Memorize these — they are the #1 lead-in to Elastic Net questions!
  1. Correlated feature instability: If x₁ and x₂ are highly correlated, Lasso arbitrarily picks one and zeros out the other — and a tiny resample can flip which one wins! (Because |2| + |0| = |1| + |1| = 2, Lasso has no strict preference for sharing weight.)
  2. The p > n saturation cap: When features exceed samples (p > n), pure Lasso can select at most n variables before saturating.[Zou & Hastie 2005]
  3. Shrinkage bias on large true coefficients: Even for huge, undeniably real features, Lasso still subtracts λ/2 — creating bias (motivation for Relaxed Lasso or Adaptive Lasso).

Interview Oral Drill · 60 seconds

Interviewer asks: "Why can't we just use the L₀ norm (counting non-zero weights) for feature selection instead of L₁? And why does Coordinate Descent work on L₁ even though |β| isn't differentiable?"

Speak your answer aloud first, then check the grading rubric
  • Why not L₀: Minimizing RSS + λ‖β‖₀ is non-convex and combinatorial (NP-hard — testing 2ᵖ subsets). L₁ is the tightest convex relaxation of L₀, making global optimization tractable in polynomial time.
  • Why Coordinate Descent works: Because the non-smooth penalty Σ|βⱼ| is separable across coordinates, optimizing one βⱼ at a time has an exact closed-form subgradient update (soft-thresholding) and is guaranteed to reach the global optimum of the convex objective.
