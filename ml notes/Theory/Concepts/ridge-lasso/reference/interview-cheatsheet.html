Non-Negotiable Rules & Why They Matter

  1. Always standardize predictors before fitting (x̃ⱼ = (xⱼ − μⱼ) / sⱼ). Why: Doubling a feature's unit halves its βⱼ, changing Ridge's penalty by 4× and Lasso's by 2×. Without standardization, units dictate shrinkage.
  2. Never penalize the intercept β₀ (or center y and X so β̂₀ = ȳ). Why: Shrinking β₀ shifts predictions toward zero instead of ȳ, making predictions depend on the arbitrary origin of y.
  3. Standardize INSIDE each CV fold using a Pipeline. Why: Fitting StandardScaler on the full dataset leaks validation mean/variance into training and optimistically biases CV error.
  4. Never compare raw λ across Ridge and Lasso (or across libraries). Why: L₂ scales quadratically while L₁ scales linearly; plus scikit-learn scales Lasso's RSS by 1/(2n) but Ridge's RSS without 1/(2n).
  5. Prefer the 1-SE rule when CV curves are flat near the minimum. Why: Picks the simplest (highest-λ) model statistically indistinguishable from the CV minimum, improving generalization and interpretability.

10 Classic Interview Triggers → 1-Sentence Punchlines

  • "Why doesn't Ridge produce zeros?" — The L₂ gradient 2λβⱼ shrinks to 0 as βⱼ → 0 (weakening pull near zero), and geometrically the smooth sphere has no axis corners.
  • "Why does Lasso produce zeros?" — The L₁ subgradient maintains constant magnitude λ all the way to 0 (soft-thresholding dead-zone |z| ≤ λ/2), and geometrically the diamond's corners sit on the axes.
  • "Why does Ridge shrink low-variance directions more?" — By SVD, Ridge multiplies PC j by dⱼ² / (dⱼ² + λ); when dⱼ² ≪ λ, the factor approaches 0, crushing noisy collinear directions.
  • "Why can't you use ordinary gradient descent on Lasso?" — |βⱼ| has a kink at 0 (non-differentiable), so naive GD oscillates around 0 without hitting exact zeros; use Coordinate Descent or proximal gradient (ISTA/FISTA).
  • "Why does Lasso cap out at n features when p > n?" — From convex duality / KKT conditions, at most n linearly independent active columns can satisfy the optimality equations simultaneously.
  • "When does Ridge beat Lasso for pure prediction?" — When the true signal is dense (many small correlated predictors); Lasso's hard selection adds extra variance and drops useful correlated signal.
  • "Why isn't L₀ used directly?" — Counting non-zeros ‖β‖₀ is non-convex and NP-hard (2ᵖ subsets); L₁ is the tightest convex relaxation of L₀.
  • "Is Ridge/Lasso solution unique?" — Ridge is strictly convex for λ > 0 → always unique. Lasso is convex but not strictly convex when X is rank-deficient (e.g. duplicated columns or p > n) → multiple optima can share the same fitted values Xβ̂.
  • "Can I get p-values by running OLS on Lasso-selected features?" — No! Selecting and testing on the same data creates selection bias (artificially tiny p-values). Use sample splitting or selective inference.
  • "Is L₂ regularization identical to Weight Decay in neural nets?" — Identical for vanilla SGD, not identical for adaptive optimizers like Adam (where L₂ gets scaled by adaptive learning rates — hence decoupled weight decay in AdamW).
