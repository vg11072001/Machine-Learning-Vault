### How to Enable Native GitHub Pages (1-time setup, optional)
1. Go to **Settings → Pages** in `vg11072001/Machine-Learning-Vault`.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Select Branch: **`main`** and Folder: **`/ (root)`**, then click **Save**.
4. A `.nojekyll` file is already committed at the repo root so every HTML page, stylesheet, and interactive simulator under `ml notes/Theory/Concepts/` will serve cleanly at `https://vg11072001.github.io/Machine-Learning-Vault/ml%20notes/Theory/Concepts/`.
